# Campaign Link Inspector

Inspect campaign links in stored WordPress posts and pages. No tracking, account, external requests or automatic link changes.

- Repeated, empty or oddly capitalized UTM parameters, whitespace, malformed percent encoding
- Missing source, medium or campaign, same-host campaign links, parameters in the fragment
- Possible email addresses or sensitive parameter names
- Query values are omitted from the report; CSV export of the current batch

Tools > Campaign Links. Requires WordPress 6.2 and PHP 7.4. Details in [readme.txt](readme.txt).
